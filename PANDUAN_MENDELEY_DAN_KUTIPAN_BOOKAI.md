# Panduan Mendeley dan Kutipan BookAI

File referensi Mendeley: `BookAI_Referensi_Mendeley.ris`

Cara pakai di Mendeley:
1. Buka Mendeley Reference Manager.
2. Pilih `File` atau `Add new` lalu pilih `Import library` / `RIS` sesuai versi Mendeley.
3. Pilih file `BookAI_Referensi_Mendeley.ris`.
4. Setelah masuk ke library, gunakan Mendeley Cite di Microsoft Word jika dosen meminta citation field dari Mendeley.

Catatan: laporan Word sudah diberi kutipan teks dan daftar pustaka. File RIS disediakan agar referensi yang sama bisa masuk ke Mendeley.
